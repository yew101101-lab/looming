# 🕯️ Product Requirements Document (PRD): 히든 메시지 캔들 랜딩페이지

## 1. 프로젝트 개요
*   **목적:** '기다림과 서사'가 담긴 히든 메시지 캔들의 핵심 가치를 전달하고, 커스텀 제품 구매(전환)를 유도.
*   **핵심 감정:** 설렘을 동반한 애틋함, 기대감
*   **기술 스택:** React 18, Vite, 일반 CSS (Vanilla CSS)
*   **컴포넌트 설계 원칙 (Slot Pattern):** 랜딩페이지의 일관된 모션(페이드인, 패럴랙스) 적용을 위해, 각 섹션 래퍼(Wrapper) 컴포넌트를 디자인 툴의 Slot 구조처럼 설계합니다. 공통 모션 래퍼 컴포넌트의 `children` 슬롯에 텍스트, 이미지 등의 개별 콘텐츠를 주입하여 재사용성과 유지보수성을 높입니다.

## 2. 디자인 시스템 (Design System)
*   **Typography:** 
    *   전체 폰트: `아리따부리 (Arita Buri)` 적용 (우아하고 서정적인 무드)
*   **Color Palette:**
    *   `--color-bg`: `#F9F7F3` (웜 아이보리 / 배경색)
    *   `--color-text`: `#3B332C` (딥 에스프레소 / 주조색, 텍스트)
    *   `--color-accent`: `#E88C7D` (뮤티드 코랄 / 강조, CTA 버튼)

## 3. 섹션별 상세 구성 및 모션 플로우

### [Section 1] Hero (시선 압도 및 무드 세팅)
*   **레이아웃:** 100vh 풀스크린. 중앙 정렬된 타이포그래피와 그 뒤로 은은하게 깔린 캔들 이미지.
*   **요소:**
    *   메인 카피: "당신의 마음을 가장 완벽하게 들키는 시간."
    *   서브 카피: "불꽃이 닿아야만 읽을 수 있는, 애틋하고 비밀스러운 고백"
    *   배경: 촛불이 은은하게 타오르는 고해상도 캔들 이미지(또는 어두운 방 안의 빛 번짐 이미지)
*   **모션 플로우:**
    *   **진입 시 (On Load):** 텍스트가 심하게 블러(Blur: 10px) 처리되어 있다가 2초에 걸쳐 서서히 선명해지며 등장(Fade-in). 배경 이미지는 1.05배율에서 1배율로 천천히 축소됨(Scale-down).
    *   **스크롤 시:** 배경 이미지가 사용자의 스크롤 속도보다 느리게 위로 이동하며 패럴랙스 효과 시작.

### [Section 2] Empathy (공감대 형성)
*   **레이아웃:** 여백(Padding)이 매우 넓은 1단 텍스트 레이아웃.
*   **요소:**
    *   메인 카피: "뻔한 포장지 속, 다 전하지 못한 마음이 있지는 않나요?"
*   **모션 플로우:**
    *   **진입/스크롤 시 (Intersection Observer):** 뷰포트에 요소가 30% 이상 노출될 때, `filter: blur(5px)`에서 `blur(0)`으로 전환되며 Y축으로 20px 이동하며 페이드인. 

### [Section 3] Core Feature (핵심 USP - 히든 메시지)
*   **레이아웃:** 좌우 분할 구조(데스크탑 기준). 좌측은 고정된 텍스트, 우측은 스크롤에 따라 변하는 이미지 시퀀스.
*   **요소:**
    *   메인 카피: "기다림이 끝나는 순간, 비로소 당신의 이야기가 시작됩니다"
    *   이미지: 왁스가 녹기 전 캔들 ➡️ 왁스가 녹으며 글자가 희미하게 보이는 캔들 ➡️ 메시지가 선명한 캔들 (총 3장 겹침 구조)
*   **모션 플로우:**
    *   **스크롤 시:** 우측 이미지 영역이 스크롤 진행도(Scroll Progress)에 따라 opacity가 전환되며 캔들이 녹아 메시지가 나타나는 과정을 슬로우 패럴랙스로 연출.

### [Section 4] Quality (제품력 신뢰)
*   **레이아웃:** 중앙 정렬 텍스트 블록 아래 3개의 세로형 이미지/설명 카드 배치.
*   **요소:**
    *   메인 카피: "마지막 불꽃이 사그라들어도 곁에 머무는 짙은 여운"
*   **모션 플로우:**
    *   **스크롤 시:** 3개의 카드가 좌측부터 순차적으로(Staggered) 블러 아웃 & 페이드 인 등장.
    *   **호버 시 (On Hover):** 텍스트 카드에 마우스 오버 시 미세하게 Y축 상승 및 그림자 강조.

### [Section 5] Use Case (상황 제시)
*   **레이아웃:** 지그재그(Zig-zag) 레이아웃. 텍스트와 이미지 교차 배치.
*   **요소:**
    *   메인 카피: "눈물이 날 만큼 애틋한, 단 하나의 서프라이즈"
*   **모션 플로우:**
    *   **스크롤 시:** 텍스트와 이미지가 서로 반대 방향(위/아래)으로 미세하게 움직이는 패럴랙스 적용.

### [Section 6] Final CTA (구매 전환)
*   **레이아웃:** 70vh 높이의 하단 섹션. 중앙에 강렬한 타이포와 버튼 배치.
*   **요소:**
    *   메인 카피: "지금, 가장 깊은 진심을 새겨보세요"
    *   CTA 버튼: `[ 나만의 진심 새기기 ]` (배경색 `#E88C7D`, 텍스트색 `#F9F7F3`)
*   **모션 플로우:**
    *   **진입 시:** 배경이 은은하게 어두워지며 촛불이 켜진 듯한 무드 연출.
    *   **호버 시:** CTA 버튼에 마우스 오버 시 버튼 내부에 빛이 지나가는(Shimmer) 효과.

## 4. 인터랙션 포인트 목록 (Interaction Points)

1.  **마우스 커서 (Custom Cursor):**
    *   일반 상태: 기본 커서 대신 작은 웜 아이보리 색상의 원형 도트(`#F9F7F3`, `opacity: 0.6`).
    *   클릭 가능한 요소(버튼, 링크) 호버 시: 도트의 크기가 2배 커지며 `mix-blend-mode: difference` 적용.
2.  **버튼 호버 (Button Hover):**
    *   CTA 버튼 호버 시 배경색 `#E88C7D`가 살짝 더 밝아지며(`filter: brightness(1.1)`), 아리따부리 폰트의 자간(Letter-spacing)이 1px 미세하게 넓어짐.
3.  **글로벌 스크롤 (Global Scroll):**
    *   일반적인 딱딱한 스크롤 대신, Lenis나 자체 CSS(`scroll-behavior: smooth`)를 활용하여 전체적으로 부드럽고 여유로운 스크롤 호흡을 유도.

## 5. 모바일 대응 방향 (Responsive Web Strategy)

모바일 환경에서는 '성능'과 '직관적인 조작'을 최우선으로 하여 과도한 연산을 줄입니다.

*   **레이아웃 전환:**
    *   섹션 3 (Core Feature)의 좌우 분할 스크롤 모션은 상하(Top-Bottom) 구조로 변경합니다.
    *   텍스트가 위, 캔들이 녹는 이미지 시퀀스가 아래에 배치되며 스크롤 대신 터치 스와이프(또는 탭)로 이미지가 변하도록 직관성을 높입니다.
*   **패럴랙스 제한:**
    *   모바일 환경(특히 iOS Safari)에서는 `background-attachment: fixed` 및 무거운 자바스크립트 패럴랙스 연산이 버벅거림을 유발할 수 있습니다. 
    *   모바일 분기(`@media (max-width: 768px)`)에서는 패럴랙스 효과를 최소화하고, 순수 CSS 애니메이션(`transform: translateY()`, `opacity`) 기반의 **블러 & 페이드인**만 유지합니다.
*   **인터랙션(Hover ➡️ Touch):**
    *   터치 디바이스에서는 마우스 커서 이펙트를 비활성화(`display: none`)합니다.
    *   버튼 호버 이펙트 대신, 터치 시( `:active` ) 버튼이 살짝 눌리는(`transform: scale(0.98)`) 직관적인 피드백을 제공합니다.
*   **타이포그래피 스케일링:**
    *   아리따부리의 가독성을 위해 모바일에서는 `font-size`를 줄이되, `line-height`를 `1.6` 이상으로 충분히 확보하여 글자가 뭉쳐 보이지 않도록 조정합니다.
